# FocusBoard – Task Management Dashboard

A modern and responsive task management dashboard built using **React.js, JavaScript, HTML, and CSS**. FocusBoard is designed to help users organize their daily activities, manage tasks efficiently, and track their productivity through a clean and intuitive interface.

## 🚀 Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Task Management:** Create, view, update, and delete tasks.
- **Task Organization:** Organize tasks based on their status and priority.
- **Progress Tracking:** Monitor task completion and overall productivity.
- **Interactive UI:** Simple navigation and user-friendly interactions.
- **Modern Interface:** Clean white-themed design with a consistent layout.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Git and GitHub

## 📂 Project Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Mansoorsk12/FocusBoard.git
```

### 2. Navigate to the Project Directory

```bash
cd FocusBoard
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.
